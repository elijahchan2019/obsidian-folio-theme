# Folio

![Folio 主题预览](screenshot.png)

**一款为 Obsidian 打造的编辑式主题。**<br>
安静地阅读，清楚地思考。

[English](README.md) · 亮色与暗色 · 桌面端与移动端 · 无需插件

Folio 让长文档拥有手稿般的阅读节奏。温暖的纸张色降低屏幕刺激，舒展的排版、克制的颜色和安静的控件把注意力留给正文。

它适合写作、研究，也适合需要长时间停留在同一份文档中的知识工作。

## 设计语言

Folio 用一套紧凑的色板建立层级：

| 色彩 | 用途 |
| --- | --- |
| 象牙白 | 阅读与书写表面 |
| 页岩灰 | 正文与标题 |
| 陶土色 | 链接、焦点、选区与激活状态 |
| 炭黑 | 暗色模式表面 |

亮色模式用深浅不同的暖象牙色区分编辑器、侧栏、标签页和浮层。暗色模式沿用同一套层级关系，以炭黑色系重新配色，不做简单反相。

标题与正文默认使用同一套无衬线字体。中英文混排在不同字号和平台下能保持稳定。界面文字降低存在感，代码则使用独立的等宽字体栈。

## 塑造页面的细节

- **排版：** 17px 阅读字号、舒展行高、克制的标题比例，以及清楚的章节间距
- **引用：** 小型引号与缩进取代常见的竖向边框
- **表格：** 顶线、表头分隔线和底线构成三线表，没有竖线、斑马纹和卡片外框
- **链接与标签：** 链接平时继承正文颜色，悬停时转为陶土色；标签使用浅陶土底色
- **任务：** 圆形复选框以陶土色填充，完成项降低透明度，不加删除线
- **导航：** 文件树和大纲用细陶土色灵动条标记当前位置
- **Callout：** 十一种语义色使用轻微染色背景和窄强调边
- **代码：** 暖调语法色区分关键字、字符串、数字、注释与符号
- **纸张质感：** 细微底噪只出现在阅读表面，打印和 PDF 导出时自动移除

Folio 也覆盖属性、嵌入、Canvas、菜单、模态框、输入框、设置页、键盘焦点、高对比度与减少动画偏好。

## 可选代码片段

Folio 保留一个明确的默认外观。仓库附带几种有边界的变化：

- [`folio-heading-font-serif.css`](snippets/folio-heading-font-serif.css) 只把标题切回衬线体，正文和界面仍使用无衬线字体。
- [`folio-font-serif-anthropic.css`](snippets/folio-font-serif-anthropic.css) 将正文与标题切换为以 Charter 和中文衬线回退为主的阅读字体栈。
- [`folio-h2-color.css`](snippets/folio-h2-color.css) 为 H2 标题加入温和的陶土色。

将代码片段复制到 `<vault>/.obsidian/snippets/`，然后在 **设置 → 外观 → CSS 代码片段** 中启用。

## 安装

从 Obsidian 社区主题市场安装：

1. 打开 **设置 → 外观 → 主题 → 管理**。
2. 搜索 **Folio**。
3. 安装并启用主题。

手动安装时，从[最新版本](https://github.com/elijah7x/theme-folio/releases/latest)下载 `theme.css` 和 `manifest.json`，放入：

```text
<vault>/.obsidian/themes/Folio/
```
